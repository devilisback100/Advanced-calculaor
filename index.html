Calculator :-

How to use

  1. Basic operation (+,/,*,-)
    • You have to just write your expression and you have to click '=' button in Calculator
  2. Algoritham operation (X!,1/x,x2,x3,√,%,π )
    • for all these function you have write your expression and then click on that button to calculate result
    • Like to use x2 for 3 so first write 3 and click on x2 and then you get 9
  3. Trigonemetric operation (sin,cos,tan)
    • for all these function you have write your expression and then click on that button to calculate result
    • Like to use sin for 45 deg sin and so first write 45 and then you click sin and then get 0.7071067811865475
    • This will get exact value in decimal
  4. Calculus operator (log and exponential)
    • for all these function you have write your expression and then click on that button to calculate result
    • Like to use log for 1 and so first write 1 and then click on lg and you get 1
  5. specific operator (Lcm,Gcf,C,←)
    • 'C' use to clear all expression and result
    • ← is used to clear expression by one one charcter
    • Lcm,Gcf is used to find lowest common factor and greatest common factor of two no. which are separated by comma respectively
    • if you have to find lcm of 7 and 14 then you have to write 7 and then ',' and 14 and then click on lcm and then you got your result as 14
  • you have to give valid expression for best result
